# Carpeta de imágenes

Coloca aquí tus fotos reales con estos nombres exactos para que se vean automáticamente en el sitio:

- `foto-principal.jpg` → foto de portada en la página de inicio.
- `abraham-1.jpg`, `abraham-2.jpg` → fotos de Abraham.
- `nosotros-1.jpg`, `nosotros-2.jpg` → fotos de ambos juntos.
- `mon-laferte-1.jpg`, `mon-laferte-2.jpg` → fotos de Mon Laferte.

Si un archivo no existe todavía, la página mostrará una imagen de reemplazo automática para que nada se vea roto.
