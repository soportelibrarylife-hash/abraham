# Carpeta de audio

Coloca aquí tus archivos mp3 reales con estos nombres exactos:

- `cancion1.mp3` → Amárrame - Mon Laferte
- `cancion2.mp3` → Tu falta de querer - Mon Laferte
- `cancion3.mp3` → La trenza - Mon Laferte
- `musica-fondo.mp3` → música de fondo que se activa con el botón "🔈 Música" en la parte superior de cada página.

Recuerda usar únicamente música que tengas derecho a utilizar/compartir.
